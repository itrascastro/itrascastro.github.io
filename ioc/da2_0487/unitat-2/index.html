Unitat 2

Desenvolupament de programari i entorns de desenvolupament (RA1 i RA2)

Descripció de la Unitat

Aquesta unitat explica el recorregut complet que hi ha entre una idea i un programa en funcionament. Començarem distingint codi font, codi objecte, codi executable, compilació, interpretació i màquina virtual; després situarem els principals paradigmes de programació i les fases de desenvolupament d'un sistema d'informació.

La segona meitat és pràctica. Treballarem amb Eclipse, instal·larem i entendrem els connectors que amplien l'IDE, construirem interfícies d'escriptori amb Java Swing i WindowBuilder, farem una aplicació web mínima amb Spring Boot i practicarem l'ús crític d'un assistent d'IA integrat a l'entorn. Els exemples comencen petits i van incorporant una sola dificultat cada vegada.

Resultats d'aprenentatge treballats

RA1Reconeix els elements i les eines que intervenen en el desenvolupament d'un programa informàtic, analitzant-ne les característiques i les fases fins a la posada en funcionament.
RA2Avalua entorns integrats de desenvolupament analitzant-ne les característiques per editar codi font i generar o empaquetar programes executables.
Informació

Com estudiar aquesta unitat

Feu sempre el recorregut complet: primer enteneu el concepte, després proveu l'exemple mínim i, finalment, canvieu una condició de l'exemple. Si només copieu pantalles o codi, qualsevol canvi de l'enunciat us bloquejarà. Si enteneu què entra, què es valida, què canvia d'estat i què surt, podreu construir una aplicació més gran sense haver-la memoritzat.

2.1

Del codi font a l'execució

Què aprendreu:

  • Distingireu programa, procés d'execució i relació amb memòria, processador i perifèrics.
  • Entendreu la diferència entre codi font, objecte, executable i biblioteques.
  • Comparareu compilació, interpretació, enllaçament i execució sobre una màquina virtual.
  • Seguireu pas a pas el recorregut d'un programa Java des del fitxer .java fins a la JVM.
  • Situareu la classificació per generacions de llenguatges que utilitza el material del mòdul.

2.2

Paradigmes i cicle de desenvolupament

Què aprendreu:

  • Aplicareu seqüència, selecció i iteració i entendreu el disseny descendent.
  • Relacionareu abstracció, encapsulació, modularitat, jerarquia i polimorfisme amb codi Java senzill.
  • Diferenciareu herència, sobrecàrrega i sobreescriptura.
  • Reconeixereu els paradigmes funcional i lògic sense memoritzar definicions aïllades.
  • Ordenareu les cinc fases de Mètrica 3 i sabreu què es decideix en cadascuna.

2.3

Eclipse i aplicacions d'escriptori amb Swing

Què aprendreu:

  • Identificareu les funcions d'un IDE i les principals peces de l'entorn Eclipse.
  • Relacionareu JDK, JRE i JVM i configurareu un entorn Java de desenvolupament.
  • Treballareu amb projectes, perspectives, vistes, connectors i actualitzacions.
  • Construireu una interfície Swing amb WindowBuilder a partir d'un exemple mínim.
  • Validareu camps, gestionareu esdeveniments, focus, combos, tooltips i estats habilitat/deshabilitat.
  • Diferenciareu fitxers .class, JAR, WAR i EAR.

2.4

Spring i assistents d'IA dins l'IDE

Què aprendreu:

  • Entendreu el model client-servidor i el paper de Spring Boot, Spring Web i Tomcat.
  • Creareu i executareu un projecte Spring senzill des d'Eclipse.
  • Connectareu un formulari HTML amb rutes GET i paràmetres d'un controlador Java.
  • Aprendreu a modificar un exemple existent sense reconstruir-lo de zero.
  • Diagnosticareu el conflicte habitual del port 8080.
  • Utilitzareu un assistent d'IA dins l'IDE com a eina de suggeriment, no com a font infal·lible.
