1. Client-servidor i Spring Boot

Una aplicació web senzilla té, com a mínim, dues peces: un client que envia una petició i un servidor que la rep, executa codi i retorna una resposta.

Spring és un framework modular. En aquesta unitat utilitzarem Spring Boot per reduir configuració i Spring Web per atendre peticions HTTP.

PeçaPaper
NavegadorClient: envia peticions i mostra HTML.
HTTPProtocol de comunicació.
Spring BootArrenca i configura l'aplicació amb convencions útils.
Spring WebPermet mapar rutes HTTP a mètodes Java.
TomcatServidor web/aplicacions. Spring Boot en pot portar un d'integrat per executar el projecte.
Informació

Model mental

Una ruta és com una porta. / pot mostrar el formulari i /dobla pot rebre el valor enviat pel formulari. Les anotacions de Spring indiquen quin mètode Java hi ha darrere de cada porta.

Exercici: Dibuixa una petició
Dibuixeu quatre caixes per representar què passa quan el navegador demana http://localhost:8080/saluda?nom=Laia: navegador, HTTP, controlador Spring i resposta.
Bàsic 6 min
Veure pistes
  • La petició va cap al servidor.
  • La resposta torna al navegador.
  • El controlador llegeix el paràmetre.

2. Crear un projecte Spring a Eclipse

El material complementari utilitza Spring Tools dins Eclipse. El procediment pot canviar lleugerament de nom entre versions, però el flux és estable.

Informació

Versions recomanades per al curs 2026-27

Utilitzeu Spring Tools 5.4.x, Spring Boot 4.1.x estable i JDK 25 LTS. Spring Boot 4.1.x és compatible amb Java 17-26, de manera que JDK 25 és una opció adequada. Si l'assistent ofereix versions amb sufixos M (Milestone), RC o SNAPSHOT, no les trieu per a les pràctiques: utilitzeu una versió estable.

1. Instal·lar les eines

  1. Obriu Help → Eclipse Marketplace....
  2. Busqueu Spring Tools.
  3. Instal·leu la versió estable compatible amb el vostre Eclipse (Spring Tools 5.4.x per a Eclipse 2026-09) i reinicieu l'IDE.

2. Crear el projecte

  1. File → New → Other....
  2. Busqueu Spring Starter Project.
  3. Poseu un nom al projecte i un paquet base.
  4. Seleccioneu Java i Maven com a gestor de dependències si l'assistent us ofereix l'opció.
  5. Afegiu Spring Web. Si el material del curs ho indica, podeu afegir també les eines de serveis web.
  6. Finalitzeu l'assistent i espereu que Maven descarregui les dependències.

L'assistent crea una classe principal amb @SpringBootApplication i un mètode main. Aquesta classe és el punt d'entrada de l'aplicació.

Important

Respecteu el paquet base.

Poseu els controladors al mateix paquet o en un subpaquet de la classe principal. Així Spring els detectarà automàticament durant l'escaneig de components.

Exercici: Projecte que arrenca
Creeu un Spring Starter Project mínim amb Spring Web i executeu-lo sense afegir encara cap controlador. L'objectiu és aconseguir que l'aplicació arrenqui sense errors.
Bàsic 15 min
Veure pistes
  • No programeu res fins que el projecte base arrenqui.
  • Reviseu la consola per comprovar que el servidor s'ha iniciat.

3. Formulari, rutes i controlador

Construirem un exemple molt petit: la ruta / mostra un formulari i la ruta /dobla rep un enter i retorna el doble.

JAVA Controlador.java 
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class Controlador {

    @GetMapping("/")
    public String index() {
        return "<html><body>"
             + "<h1>Dobla el valor</h1>"
             + "<form action=\"/dobla\" method=\"GET\">"
             + "<input type=\"text\" name=\"enter\"/>"
             + "</form>"
             + "</body></html>";
    }

    @GetMapping("/dobla")
    public String resultat(@RequestParam("enter") String enter) {
        try {
            int resultat = Integer.parseInt(enter) * 2;
            return "<html><body>"
                 + "<h1>Dobla el valor</h1>"
                 + "<strong>Resultat: " + resultat + "</strong>"
                 + "</body></html>";
        } catch (NumberFormatException e) {
            return "<html><body>"
                 + "<h1>El valor introduït no és un enter</h1>"
                 + "</body></html>";
        }
    }
}

Llegiu el codi com una conversa

FragmentQuè diu?
@RestControllerAquesta classe atendrà peticions web i retornarà dades/contingut en la resposta.
@GetMapping("/")Aquest mètode respon a un GET a l'arrel.
action="/dobla"En enviar el formulari, el navegador demana la ruta /dobla.
name="enter"El paràmetre de la URL s'anomena enter.
@RequestParam("enter")Spring copia aquell paràmetre a l'argument del mètode.

Si escriviu 12, el navegador acabarà demanant una URL semblant a /dobla?enter=12. El mètode resultat rep el text, el converteix i calcula.

Exercici: Del doble al quadrat
Copieu l'exemple i adapteu-lo perquè la segona ruta sigui /quadrat i mostri el quadrat del nombre introduït. Canvieu també els textos visibles del formulari.
Intermedi 15 min
Veure pistes
  • Heu de mantenir coherents @GetMapping i action.
  • El nom del paràmetre pot continuar sent enter.
  • Canvieu primer la ruta, després el càlcul i al final els textos.

4. Adaptar l'exemple a un nou requisit

La competència important no és copiar l'exemple anterior, sinó saber què canviar quan canvia l'enunciat. Suposem que ara ens demanen calcular el quíntuple i mostrar una dada identificativa sota el títol.

Feu una llista de canvis abans de tocar el codi

  1. Canviar el text del títol.
  2. Afegir una línia HTML per mostrar la dada identificativa.
  3. Canviar la ruta del formulari si l'enunciat exigeix una ruta nova.
  4. Mantenir coherent l'action del formulari i el @GetMapping.
  5. Canviar l'operació aritmètica de * 2 a * 5.
  6. Provar un valor correcte i un valor incorrecte.
Informació

Regla d'or quan adapteu exemples

Canvieu una cosa cada vegada i executeu. Si modifiqueu ruta, nom del paràmetre, HTML i càlcul alhora, qualsevol error us obligarà a revisar quatre llocs. Si ho feu per passos, sabreu exactament quin canvi ha trencat l'aplicació.

Proves mínimes

EntradaQuè hauríeu de comprovar?
25El resultat numèric és 125 i es veu la dada identificativa demanada.
0El resultat és coherent.
holaEs mostra un missatge d'error i l'aplicació continua funcionant.
Exercici: Canvi controlat
Partiu de l'exercici del quadrat i convertiu-lo en una aplicació que calculi el triple. Afegiu el vostre nom sota el títol. Feu un canvi, executeu i només després feu el següent.
Intermedi 15 min
Veure pistes
  • El procés importa tant com el resultat.
  • Anoteu quin fitxer i quina línia conceptual heu canviat en cada pas.

5. Execució, Tomcat i port 8080

Per executar el projecte, seleccioneu-lo i utilitzeu Run As → Spring Boot App. Spring Boot pot arrencar un Tomcat integrat, de manera que per a aquest exemple no cal desplegar manualment el projecte en un servidor extern.

Quan la consola indiqui que l'aplicació està en marxa, obriu:

TEXT 
http://localhost:8080

Error típic: el port 8080 ja està ocupat

El primer que heu de comprovar és si ja teniu una execució anterior de Spring oberta dins Eclipse. Atureu-la i torneu-ho a provar.

En Linux, si necessiteu identificar quin procés escolta al port, el material complementari mostra una consulta com:

BASH 
sudo netstat -lnp | grep 8080

La sortida indica el PID del procés. Només si esteu segurs que és el procés que voleu acabar, el podeu aturar. L'important no és memoritzar l'ordre: és entendre que dos servidors no poden escoltar alhora el mateix port i adreça.

Important

No mateu processos a l'atzar.

Abans d'acabar un procés del sistema, identifiqueu-lo. En la majoria de pràctiques, el problema es resol aturant l'execució anterior des de la mateixa consola d'Eclipse.

Exercici: Diagnostica el 8080
Escriviu una seqüència de diagnosi per al missatge «Port 8080 was already in use», començant per la solució menys invasiva.
Bàsic 7 min
Veure pistes
  • Primer mireu Eclipse.
  • Després identifiqueu el procés.
  • No atureu res que no hàgiu identificat.

6. Windsurf Plugin (abans Codeium): suggeriments, xat i revisió

El material complementari i l'EAC utilitzen el nom Codeium. Actualment el connector es distribueix com a Windsurf Plugin (anteriorment Codeium). És la mateixa línia d'eina amb el nom actualitzat; per tant, si l'enunciat parla de Codeium, heu de buscar el connector Windsurf Plugin per a Eclipse.

Les dues formes d'ajuda que ens interessen són:

  • suggeriments de compleció mentre escrivim codi;
  • xat per preguntar, explicar o generar fragments.

Instal·lació i accés

  1. Busqueu i instal·leu Windsurf Plugin des del Marketplace d'Eclipse. El connector és compatible amb versions modernes d'Eclipse; el nostre entorn 2026-09 queda dins del rang suportat.
  2. Autentiqueu-vos si l'eina ho requereix.
  3. Obriu la vista del xat des de la integració del connector o amb Window → Show View → Other....

Per a una segona operació sobre cadenes, prepareu primer una prova amb resultat conegut. Important

No doneu per bona una resposta perquè compila.

Un programa pot compilar i continuar sent incorrecte. L'assistent pot produir una solució plausible que no compleixi algun detall de l'enunciat. La verificació és part de la feina.

Exercici: Demana, revisa, prova
Escriviu un comentari que demani un mètode estàtic que compti dígits en una cadena. Feu que l'assistent proposi codi, expliqueu què heu escrit vosaltres i què ha completat l'eina, i proveu-lo amb «A1B22» i amb una cadena buida.
Intermedi 15 min
Veure pistes
  • El resultat esperat per A1B22 és 3.
  • No accepteu el suggeriment fins que pugueu explicar-lo.

7. De l'exemple a l'EAC

Ja disposeu de totes les peces. El secret per afrontar una activitat més gran és no intentar construir-la d'una sola vegada.

Aplicació Swing

  1. Dibuixeu els blocs de la finestra sense comportament.
  2. Configureu camps editables, no editables, tooltips i estat inicial.
  3. Implementeu la validació del primer bloc i proveu errors un per un.
  4. Implementeu el canvi d'estat: deshabilitar la primera etapa i habilitar la segona.
  5. Valideu els combos i el valor numèric de la segona etapa.
  6. Calculeu primer base i factors, després extres/descompte, després IVA i total.
  7. Implementeu l'acció de reinici al final.

Aplicació Spring

  1. Feu funcionar l'exemple mínim.
  2. Canvieu el càlcul.
  3. Afegiu el text identificatiu.
  4. Executeu una entrada correcta i una d'errònia.
  5. Només després feu la captura demanada.

Assistent d'IA

  1. Escriviu vosaltres els comentaris que descriuen els mètodes.
  2. Deixeu que l'assistent proposi codi.
  3. Reviseu i proveu cada mètode.
  4. Conserveu prou evidència per poder explicar què heu escrit i què ha suggerit l'eina.
Èxit

Si podeu fer els exemples d'aquesta unitat sense copiar-los literalment, teniu les eines necessàries per afrontar una activitat de dificultat equivalent a l'EAC.

El salt no és aprendre nous components: és combinar validació, estat de la interfície, càlculs i execució en un únic programa.

Sé validar un JTextField i un JComboBox i gestionar focus i estats enabled

Exercici: Simulació final
Sense mirar els exemples, creeu una aplicació Swing petita que validi dues dades, activi una segona etapa i calculi un total amb IVA. Després expliqueu en cinc frases com convertiríeu un exemple Spring que calcula el doble en un altre que calcula una operació diferent.
Avançat 45-60 min
Veure pistes
  • Treballeu per etapes.
  • No passeu al càlcul fins que la validació sigui estable.
  • A Spring, identifiqueu ruta, paràmetre, operació i HTML.
