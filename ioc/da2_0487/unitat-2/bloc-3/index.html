1. Què és un IDE i què aporta Eclipse

Podríem programar Java amb un editor de text i una terminal. Un IDE integra en una sola eina les operacions que repetim contínuament: editar, compilar, executar, depurar, navegar pel projecte i gestionar extensions.

FuncióQuè aporta?
EditorColoració, compleció, navegació i detecció primerenca d'errors.
Compilador/intèrpretConstrueix o executa el projecte segons el llenguatge.
DepuradorPermet aturar el programa, avançar pas a pas i inspeccionar variables.
GUI designerAjuda a construir interfícies gràfiques.
Control de versionsIntegra l'historial de canvis i operacions amb repositoris.
RefactoritzacióReestructura el codi mantenint el comportament extern.
Documentació i ajudaAccés a informació contextual i documentació.
ConnectorsAfegeixen suport per noves tecnologies o funcions.
Informació

Eclipse és extensible.

La instal·lació base no ha de contenir totes les eines possibles. El suport Java, WindowBuilder, Spring o un assistent d'IA poden aparèixer com a components o connectors que amplien l'entorn.

2. JDK, JRE, JVM i configuració

Per desenvolupar Java necessitem el JDK. Eclipse ha de saber quin JDK utilitzar per compilar i executar el projecte.

Informació

Entorn recomanat per al curs 2026-27

Treballarem amb JDK 25 LTS i una versió actual d'Eclipse (Eclipse 2026-09 en el moment de preparar aquests materials). Java 27 és més recent, però el JDK 25 és la versió LTS i ofereix una base més estable per al curs.

Comproveu Java abans d'obrir l'IDE

BASH 
java -version
javac -version

Si java funciona però javac no, probablement disposeu d'un entorn d'execució però no d'un JDK complet o el PATH no apunta a les eines correctes.

ElementFunció pràctica
JAVA_HOMEIndica la carpeta arrel del JDK a eines que necessiten localitzar-lo.
PATHPermet executar ordres com java i javac des de la terminal.
JDK configurat a EclipseDetermina amb quin conjunt d'eines es construeix el projecte.

Flux de preparació

  1. Instal·leu JDK 25 LTS, que és la versió recomanada per al curs.
  2. Verifiqueu java i javac.
  3. Instal·leu o descomprimiu Eclipse.
  4. Obriu un workspace.
  5. Comproveu a les preferències de Java que Eclipse detecta el JDK correcte.
Important

No instal·leu coses a cegues.

Si Eclipse ja compila un projecte Java senzill, el JDK està operatiu. Afegir versions noves o canviar variables sense una necessitat concreta pot crear més problemes que no pas resoldre'n.

Exercici: Diagnosi mínima
Imagineu que Eclipse s'obre però un projecte Java no troba el compilador. Escriviu tres comprovacions, en ordre, abans de reinstal·lar res.
Bàsic 8 min
Veure pistes
  • Primer comproveu la terminal.
  • Després la versió del JDK.
  • Finalment la configuració de l'IDE.

3. Projectes, perspectives, vistes i connectors

Eclipse organitza el treball en projectes. Un projecte agrupa codi font, recursos, configuració i altres fitxers relacionats. A sobre d'aquesta estructura, l'IDE presenta diferents finestres.

ConcepteImatge mental
EditorLa zona on modifiqueu un fitxer.
VistaUna finestra auxiliar: explorador de projecte, consola, problemes...
PerspectivaUn conjunt de vistes i editors organitzat per a una tasca concreta.
ConnectorUna extensió que afegeix capacitats a Eclipse.

Si desapareix una finestra, normalment no cal reinstal·lar res: proveu Window → Show View. Per canviar la disposició orientada a una tasca, utilitzeu Window → Perspective.

Instal·lar connectors

Segons el connector, el camí habitual és Help → Eclipse Marketplace... o Help → Install New Software.... El procés general és el mateix: localitzar el component, revisar què s'instal·larà, acceptar les condicions necessàries i reiniciar Eclipse.

Aquesta unitat utilitzarà dos exemples d'extensió:

  • WindowBuilder per dissenyar interfícies Swing;
  • Spring Tools per treballar còmodament amb projectes Spring.

Si WindowBuilder encara no està instal·lat

  1. Obriu Help → Install New Software....
  2. Afegiu un lloc nou amb el nom WindowBuilder i l'adreça https://download.eclipse.org/windowbuilder/updates/release/latest.
  3. Seleccioneu els components de WindowBuilder, continueu l'assistent i reinicieu Eclipse.

Utilitzeu el canal release/latest: apunta a l'última versió estable de WindowBuilder. Eviteu els canals milestone i nightly per a les pràctiques del curs. En el moment de preparar aquests materials, la versió estable és WindowBuilder 1.25.x.

Informació

RA2 no és «saber on és un menú».

El que heu d'entendre és que un IDE es pot personalitzar, ampliar i actualitzar. Els noms exactes dels menús poden variar lleugerament entre versions; la funció que busqueu és la mateixa.

Bàsic 7 min
Veure pistes
  • Show View, Perspective i Marketplace/Install New Software són tres pistes diferents.

4. Primera finestra amb WindowBuilder i Swing

Començarem amb el mateix tipus d'exemple mínim del material complementari: una finestra que llegeix un enter, calcula el doble i mostra el resultat. Només hi ha dos camps de text i un botó.

1. Crear el projecte i la finestra

  1. Creeu un Java Project.
  2. Amb WindowBuilder instal·lat, feu New → Other... → WindowBuilder → Swing Designer → Application Window.
  3. Poseu un nom a la classe, per exemple CalculaDoble.
  4. Obriu la pestanya Design.

Per a una pràctica petita de mida fixa, podeu utilitzar Absolute Layout, com fa el material complementari. En aplicacions reals més grans són preferibles gestors de disposició adaptables, però aquí l'objectiu és aprendre els components i els esdeveniments sense afegir una dificultat nova.

Important

Trieu components Swing, no SWT.

WindowBuilder pot oferir assistents per a tecnologies diferents. En aquesta unitat treballarem amb Swing Designer i components de javax.swing.

2. Afegir components

Component SwingPaperVariable d'exemple
JLabelText fix.lblTitol
JTextFieldEntrada o sortida de text.textEntrada, textResultat
JButtonAcció de l'usuari.btnDobla

El camp de resultat no l'ha de modificar l'usuari:

JAVA 
textResultat.setEditable(false);

3. Afegir el comportament

En fer doble clic al botó, WindowBuilder pot generar l'esquelet de l'ActionListener. El nostre codi va dins d'actionPerformed.

JAVA 
btnDobla.addActionListener(new ActionListener() {
    public void actionPerformed(ActionEvent e) {
        try {
            int entrada = Integer.parseInt(textEntrada.getText().trim());
            int resultat = entrada * 2;
            textResultat.setText(String.valueOf(resultat));
        } catch (NumberFormatException ex) {
            JOptionPane.showMessageDialog(null, "Introdueix un nombre enter.");
        }
    }
});

Aquest exemple ja conté el patró que repetirem: llegir → validar/convertir → calcular → mostrar.

Exercici: Del doble al triple
Reproduïu l'exemple i modifiqueu-lo perquè calculi el triple. Afegiu un tooltip al camp d'entrada i feu que el camp de sortida no sigui editable.
Bàsic 15 min
Veure pistes
  • setToolTipText defineix l'ajuda.
  • setEditable(false) protegeix la sortida.
  • Només canvia una operació aritmètica.

5. Esdeveniments, validació i errors

Una interfície gràfica espera accions de l'usuari. El botó és l'objecte que genera un esdeveniment i l'ActionListener és el codi que reacciona al clic.

Validar un enter amb rang

JAVA 
try {
    int antiguitat = Integer.parseInt(textAntiguitat.getText().trim());

    if (antiguitat < 0 || antiguitat > 150) {
        textErrors.setText("Introdueix un enter entre 0 i 150.");
        textAntiguitat.requestFocus();
        textAntiguitat.selectAll();
        return;
    }

    textErrors.setText("");
    // continuar...
} catch (NumberFormatException ex) {
    textErrors.setText("Introdueix un enter entre 0 i 150.");
    textAntiguitat.requestFocus();
    textAntiguitat.selectAll();
    return;
}

Validar un combo

Una tècnica senzilla és reservar l'índex 0 per al text «-- Selecciona --». Aleshores:

JAVA 
if (comboTipus.getSelectedIndex() == 0) {
    textErrors.setText("Selecciona un tipus.");
    comboTipus.requestFocus();
    return;
}

Canviar l'estat de la interfície

JAVA 
textAntiguitat.setEnabled(false);
comboTipus.setEnabled(false);

comboOpcio.setEnabled(true);
textDescompte.setEnabled(true);
btnCalcular.setEnabled(true);

Aquesta tècnica evita que l'usuari canviï dades que ja hem validat mentre calcula la segona part del formulari.

Important

Validar no és només convertir.

Integer.parseInt("200") és correcte sintàcticament, però si el domini només permet valors fins a 150, la dada continua sent invàlida. Primer comprovem el format i després les regles del problema.

Exercici: Primer error, primer focus
Creeu dos camps: edat (0..120) i tipus de client (combo). En prémer Validar, mostreu només el primer error, doneu focus al component corresponent i no continueu fins que sigui correcte.
Intermedi 15 min
Veure pistes
  • Useu return després de cada error.
  • Per al JTextField combineu requestFocus() i selectAll().
  • Reserveu l'índex 0 del combo.

6. Construir una interfície per etapes

Una aplicació amb molts camps deixa de ser complicada si la pensem com una màquina d'estats senzilla. En lloc de voler programar-ho tot alhora, dividim la interacció en etapes.

Mapa de components que heu de dominar

NecessitatComponent/mètode
Entrada de textJTextField, getText(), setText()
Selecció tancadaJComboBox, addItem(...), getSelectedIndex(), getSelectedItem(), getItemCount()
Bloquejar/desbloquejarsetEnabled(boolean)
Sortida no editablesetEditable(false)
Ajuda contextualsetToolTipText(...)
Marcar un error de textrequestFocus() + selectAll()
ReiniciarsetText(""), setSelectedIndex(0) i reposar els estats habilitat/deshabilitat.

Un càlcul per capes

Eviteu una fórmula gegant. Calculeu variables intermèdies que pugueu inspeccionar:

JAVA 
double base = 80.0;
double factorClient = 0.90;
double extres = 25.0;
double descompte = 10.0;

double abansImpostos = base * factorClient + extres - descompte;
double iva = abansImpostos * 0.21;
double total = abansImpostos + iva;

Amb variables separades podeu provar cada regla de negoci de forma independent i detectar molt més ràpidament on hi ha un error.

Èxit

Estratègia recomanada

  1. Feu que la finestra tingui l'aspecte correcte.
  2. Implementeu només la validació del primer bloc.
  3. Activeu/desactiveu la segona etapa.
  4. Valideu la segona etapa.
  5. Feu els càlculs.
  6. Implementeu «esborrar/reiniciar» al final.
Exercici: Quota mensual
Creeu una mini aplicació amb tipus de quota (Bàsica 20 €, Plus 35 €), un extra Sí/No de 5 € i un descompte numèric. Valideu primer la quota, després l'extra i el descompte, i mostreu base, IVA del 21 % i total.
Intermedi 25 min
Veure pistes
  • No programeu totes les validacions a la vegada.
  • Reserveu un valor «-- Selecciona --» als combos.
  • Calculeu base, abansImpostos, iva i total en variables diferents.

7. Empaquetar i executar: CLASS, JAR, WAR i EAR

En Java, Eclipse genera bytecode en fitxers .class. Per distribuir una aplicació, és habitual encapsular diversos fitxers en un paquet.

FormatÚs principal
.classBytecode d'una classe Java.
JARJava Archive: agrupa classes i recursos; pot representar una aplicació Java distribuïble.
WARWeb Application Archive: empaqueta una aplicació web Java per al seu desplegament.
EAREnterprise Archive: agrupa diversos mòduls d'una aplicació empresarial.

Per a una aplicació d'escriptori senzilla, el format que més us interessa és el JAR. L'IDE pot automatitzar l'exportació, però el JAR continua necessitant una JVM compatible per executar el bytecode.

Informació

No confongueu «executar des d'Eclipse» amb «tenir un .exe».

En Java, l'objectiu habitual és generar bytecode i empaquetar-lo. La JVM és qui proporciona la capa d'execució sobre cada plataforma.

Exercici: Quin paquet faries servir?
Trieu entre class, JAR, WAR o EAR per a: una única classe compilada, una aplicació Java d'escriptori, una aplicació web Java i un paquet empresarial amb diversos mòduls.
Bàsic 6 min
Veure pistes
  • Penseu en classe, aplicació d'escriptori, web i conjunt de mòduls.
