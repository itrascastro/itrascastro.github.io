Unitat 1

Introducció al disseny orientat a objectes (modelatge UML) (RA5 i RA6)

Descripció de la Unitat

Aquesta unitat introdueix el modelatge orientat a objectes amb UML des d'una idea molt concreta: abans de dibuixar un diagrama cal entendre què volem explicar. Per això començarem amb exemples mínims —una sola classe, una relació, una decisió, una seqüència curta— i només després combinarem les peces en models més complets.

Treballarem els diagrames de classes i els principals diagrames de comportament que apareixen a les activitats del mòdul. També aprendrem a utilitzar Papyrus per construir-los, exportar-los, generar codi Java i fer el recorregut invers: obtenir classes UML a partir de codi existent.

Resultats d'aprenentatge treballats

RA6Genera diagrames de comportament valorant-ne la importància en el desenvolupament d'aplicacions i emprant eines específiques.
Informació

Com estudiar aquesta unitat

No memoritzeu una col·lecció de símbols. Davant de cada enunciat feu sempre les mateixes preguntes: quins conceptes existeixen?, quines dades tenen?, què poden fer?, com es relacionen?, qui inicia cada acció?, en quin ordre passen les coses?, quines decisions o canvis d'estat hi ha? Si aquestes preguntes tenen resposta, el diagrama gairebé surt sol.

1.1

Del problema al primer diagrama de classes

Què aprendreu:

Aprendreu a passar d'un text informal a un primer model orientat a objectes.

  • Què és UML i què diferencia una visió estàtica d'una de comportament.
  • Com representar classes, atributs, operacions i visibilitat.
  • Quina diferència hi ha entre una classe i un objecte.
  • Com crear un primer projecte i un primer diagrama de classes amb Papyrus.

1.2

Relacions entre classes i modelatge complet

Què aprendreu:

Aprendreu a convertir frases com «un client pot fer moltes comandes» o «un motor no té sentit sense el dron» en relacions UML precises.

  • Associacions i multiplicitats llegides en les dues direccions.
  • Generalització, dependència i interfícies.
  • Diferència entre agregació i composició.
  • Classes associatives i relacions amb informació pròpia.
  • Mètode sistemàtic per resoldre un enunciat complet.

1.3

Diagrames de comportament i d'interacció

Què aprendreu:

Aprendreu a escollir i construir el diagrama de comportament adequat segons la pregunta que voleu respondre.

  • Actors, casos d'ús i límit del sistema.
  • Relacions <<include>> i <<extend>>.
  • Ordre temporal amb diagrames de seqüència.
  • Col·laboració entre objectes amb diagrames de comunicació.
  • Decisions i paral·lelisme amb diagrames d'activitats.
  • Cicle de vida d'un objecte amb diagrames d'estats.

1.4

Papyrus de principi a fi: del model al codi i del codi al model

Què aprendreu:

Convertireu el coneixement UML en un flux de treball complet amb Papyrus.

  • Organitzar projectes, models i diagrames sense confondre'ls.
  • Editar, revisar i exportar els diagrames que heu construït.
  • Generar classes Java a partir d'un diagrama de classes.
  • Configurar l'extensió necessària i fer enginyeria inversa de Java a UML.
  • Aplicar una revisió final que detecti els errors més freqüents abans de lliurar.
