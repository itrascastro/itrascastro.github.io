Unitat 1

Interfícies gràfiques amb editor visual i components visuals (RA1, RA3)

Descripció de la Unitat

Disseny d'interfícies amb l'editor visual de Windows Forms i creació de components visuals reutilitzables propis.

Resultats d'aprenentatge treballats

RA1Genera interfícies gràfiques d'usuari mitjançant editors visuals utilitzant les funcionalitats de l'editor i adaptant el codi generat.
RA3Crea components visuals valorant i emprant eines específiques.
