A1. Primers passos amb C#

Variables, condicions, bucles i entrada de dades

En acabar sabreu:
  • Executar un programa senzill de consola.
  • Entendre variables, tipus, condicions i bucles.
  • Identificar la diferència entre una instrucció i un bloc de codi.

1. Per què necessitem aquest annex?

Als materials de DAM_0488 treballareu amb C#, .NET i Windows Forms. Si veniu d'un altre llenguatge, o no heu fet programació orientada a objectes ni per esdeveniments, aquest annex us permet adquirir les bases abans de començar el projecte GestorEstocBotiga de la unitat 1.

Què NO és aquest annex

No és un curs exhaustiu de C#. És una introducció pràctica per llegir, entendre i modificar els exemples del mòdul. No substitueix les tres unitats ni afegeix cap resultat d'aprenentatge nou.

2. Preparar C# i crear el primer programa

Per als exercicis de consola podeu utilitzar el .NET SDK 8 o posterior a Windows, Linux o macOS. Els exercicis de Windows Forms dels blocs A3 i A4 requereixen Windows i Visual Studio amb la càrrega .NET desktop development.

Obriu un terminal i executeu aquestes ordres. L'última inicia el programa:

TERMINALTerminal
dotnet --version
dotnet new console -n PrimerCSharp
cd PrimerCSharp
dotnet run

En aquest projecte trobareu un fitxer Program.cs. Substituïu-ne el contingut per:

C#Program.cs
Console.WriteLine("Hola, DAM_0488!");
Console.WriteLine("Estic aprenent C#.");

Executeu dotnet run una altra vegada. Console.WriteLine mostra text. El símbol ; acaba la instrucció, i les cometes delimiten text literal.

On s'executa aquest codi?

Una aplicació de consola comença per les instruccions de Program.cs i s'acaba quan arriba al final. En Windows Forms, en canvi, es mostra una finestra i el programa espera esdeveniments de l'usuari. Veureu aquest canvi al bloc A3.

3. Variables i tipus de dades

Una variable té un nom, un tipus i un valor. Els tipus més habituals són int (enter), double (decimal), bool (cert/fals) i string (text).

C#Program.cs
string nom = "Teclat";
int unitats = 12;
double preu = 19.95;
bool disponible = unitats > 0;

Console.WriteLine(nom);
Console.WriteLine(unitats * preu);
Console.WriteLine(disponible);

var deixa que el compilador dedueixi el tipus: var total = 3; és un enter. C# continua sent un llenguatge fortament tipat; no podeu posar un text en una variable int.

4. Decisions i repeticions

C#Program.cs
int estoc = 4;

if (estoc == 0)
{
    Console.WriteLine("Esgotat");
}
else if (estoc < 5)
{
    Console.WriteLine("Estoc baix");
}
else
{
    Console.WriteLine("Disponible");
}

for (int i = 0; i < 3; i++)
{
    Console.WriteLine("Revisió " + i);
}

Fixeu-vos en = (assignació) i == (comparació). Amb if decidim què executar; amb for repetim una tasca mentre la condició sigui certa. Les claus { } delimiten cada bloc.

5. Llegir dades sense fer fallar el programa

Un camp de formulari i Console.ReadLine() retornen text. Per convertir-lo a enter és millor utilitzar int.TryParse i comprovar si és vàlid:

C#Program.cs
Console.Write("Quantes unitats hi ha? ");
string? entrada = Console.ReadLine();

if (int.TryParse(entrada, out int quantitat) && quantitat >= 0)
{
    Console.WriteLine("Quantitat correcta: " + quantitat);
}
else
{
    Console.WriteLine("Introduïu un enter no negatiu.");
}

L'operador && significa «i». L'operador ? a string? indica que el valor podria ser null, és a dir, que podria no haver-hi cap text.

Practiqueu: Primer classificador d'estoc

Feu un programa que demani una quantitat i mostri «Esgotat» si és 0, «Estoc baix» si és entre 1 i 4, i «Disponible» si és 5 o més. Si la dada no és vàlida, mostreu un missatge clar. Proveu les entrades 0, 3, 8, -1 i hola.

Comprovació abans de continuar
  • Entenc què fan string, int i bool.
  • Sé diferenciar = i ==.
  • Sé explicar què fa un if i què fa un for.
  • Sé validar un número amb int.TryParse.
