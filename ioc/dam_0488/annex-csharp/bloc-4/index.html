A4. Miniaplicació guiada: catàleg de productes

Una primera aplicació completa amb C# i Windows Forms

En acabar sabreu:
  • Crear una classe Producte i un formulari senzill.
  • Validar dades i respondre als clics d'un botó.
  • Afegir productes a una llista i mostrar-los.
  • Comprovar errors habituals abans d'entrar a la unitat 1.

1. Què construirem?

Ara ajuntarem les idees anteriors en una aplicació Windows Forms molt senzilla. Podreu escriure un nom i una quantitat, prémer Afegir i veure els productes en una llista. És un exercici introductori, no el projecte complet de la unitat 1.

TextBox→Click→Validació→Producte→ListBox

2. Crear el projecte i els controls

  1. A Windows, creeu un projecte Windows Forms App (C#) anomenat MiniCataleg.
  2. Al dissenyador de Form1, afegiu dos TextBox: txtNom i txtQuantitat.
  3. Afegiu un Button anomenat btnAfegir, amb el text «Afegir».
  4. Afegiu un ListBox anomenat lstProductes.
  5. Afegiu un Label anomenat lblTotal, amb el text «Productes: 0».
  6. Deseu. No cal modificar manualment Form1.Designer.cs.

Podeu posar també labels explicatius «Nom» i «Quantitat» per indicar què correspon a cada camp. El nom exacte dels controls és important perquè els fragments següents coincideixin amb el dissenyador.

3. Crear la classe Producte

Afegiu un fitxer de classe Producte.cs al projecte. Feu servir el mateix namespace que teniu al vostre Form1.cs. Si el projecte es diu MiniCataleg, podeu utilitzar:

C#Producte.cs
namespace MiniCataleg;

public class Producte
{
    public string Nom { get; }
    public int Quantitat { get; }

    public Producte(string nom, int quantitat)
    {
        Nom = nom;
        Quantitat = quantitat;
    }

    public override string ToString()
    {
        return Nom + " (" + Quantitat + ")";
    }
}

ToString() defineix com es representarà el producte quan el posem dins del ListBox. En lloc de mostrar el nom de la classe, apareixerà, per exemple, Teclat (5).

4. Programar el formulari i el Click

Obriu Form1.cs. Si el dissenyador ja ha creat la classe i el constructor, no els dupliqueu: incorporeu-hi el camp, la connexió del Click i el mètode. Aquest és un exemple complet de la lògica del formulari:

C#Form1.cs
namespace MiniCataleg;

public partial class Form1 : Form
{
    private readonly List<Producte> productes = new();

    public Form1()
    {
        InitializeComponent();
        btnAfegir.Click += BtnAfegir_Click;
    }

    private void BtnAfegir_Click(object? sender, EventArgs e)
    {
        string nom = txtNom.Text.Trim();

        if (nom.Length == 0)
        {
            MessageBox.Show("Cal indicar el nom del producte.");
            txtNom.Focus();
            return;
        }

        if (!int.TryParse(txtQuantitat.Text, out int quantitat)
            || quantitat < 0)
        {
            MessageBox.Show("La quantitat ha de ser un enter no negatiu.");
            txtQuantitat.Focus();
            return;
        }

        Producte nou = new Producte(nom, quantitat);
        productes.Add(nou);
        lstProductes.Items.Add(nou);
        lblTotal.Text = "Productes: " + productes.Count;

        txtNom.Clear();
        txtQuantitat.Clear();
        txtNom.Focus();
    }
}

Què passa quan premeu el botó? El formulari llegeix les dues entrades; comprova que siguin correctes; crea un objecte Producte; l'afegeix a una llista de dades i al ListBox; actualitza el comptador; i deixa el formulari preparat per a un altre producte.

Si feu servir l'editor d'esdeveniments del dissenyador

Si ja heu associat BtnAfegir_Click a Click amb la icona del llamp o fent doble clic al botó, elimineu la línia btnAfegir.Click += BtnAfegir_Click; del constructor. El gestor només ha d'estar subscrit una vegada.

6. Activitats de millora, per ordre

Practiqueu: Nivell 1 · Botó Neteja

Afegiu un botó btnNeteja que buidi només els TextBox. Practiqueu Clear() i Focus().

Practiqueu: Nivell 2 · Evitar noms duplicats

Abans de crear un producte, recorreu la llista productes i detecteu si ja n'hi ha un amb el mateix nom, ignorant majúscules i minúscules. Mostreu un missatge i no el dupliqueu. Pista: string.Equals(a, b, StringComparison.OrdinalIgnoreCase).

Practiqueu: Nivell 3 · Eliminar l'element seleccionat

Afegiu un botó btnEliminar. Si lstProductes.SelectedItem és un Producte, elimineu-lo de la llista productes i del ListBox. Actualitzeu el Label. Si no hi ha cap selecció, aviseu l'usuari.
