Iniciació a C# i programació per esdeveniments

Una guia pràctica i breu pensada per a qui comença de zero amb C# o no domina encara les classes i la programació per esdeveniments.

Objectiu: seguir amb autonomia els exemples de la Unitat 1 de DAM_0488, especialment el projecte GestorEstocBotiga, els formularis Windows Forms i els components visuals.

Abans de començar

Els blocs A1 i A2 es poden practicar en qualsevol sistema operatiu amb .NET. Els blocs A3 i A4 requereixen Windows i Visual Studio amb el dissenyador Windows Forms. Els exercicis estan pensats per completar-se en ordre, amb exemples que podeu executar i modificar.

Annex Itinerari de reforç (4 blocs)

A1

Variables, condicions, bucles i entrada de dades

A2

Organitzar el codi amb mètodes, classes i objectes

A3

Del programa seqüencial als botons i formularis

A4

Una primera aplicació completa amb C# i Windows Forms

Recorregut recomanat

  1. A1. Aprendre els elements mínims del llenguatge: variables, condicions, bucles i dades d'entrada.
  2. A2. Construir classes amb dades i mètodes, i utilitzar objectes i llistes.
  3. A3. Crear un formulari visual i entendre què passa quan un usuari fa clic.
  4. A4. Reunir-ho tot en una aplicació senzilla amb validació i una llista de productes.
Què cal dominar en acabar
  • Llegir un fragment senzill de C# i entendre les seves instruccions.
  • Distingir classe, objecte, propietat, constructor i mètode.
  • Connectar el clic d'un Button a un mètode en un Form.
  • Utilitzar una classe pròpia des del formulari.
  • Validar una entrada abans de modificar l'estat de l'aplicació.
