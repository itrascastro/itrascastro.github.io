A2. Mètodes, objectes i classes

Organitzar el codi amb mètodes, classes i objectes

En acabar sabreu:
  • Crear i cridar mètodes amb paràmetres i retorn.
  • Entendre què és una classe i què és un objecte.
  • Utilitzar constructors, propietats i llistes.

1. Mètodes: dividir un problema

Un mètode és una operació amb nom que podeu executar des de diversos llocs. Rep paràmetres i pot retornar un resultat. Això evita repetir instruccions.

C#Program.cs
int stockFinal = SumarUnitats(5, 3);
Console.WriteLine(stockFinal);

static int SumarUnitats(int actuals, int noves)
{
    return actuals + noves;
}

static significa que el mètode no necessita una instància d'una classe. Més endavant utilitzarem mètodes que pertanyen a un objecte concret. Si un mètode no retorna cap valor, el seu tipus de retorn és void.

C#Program.cs
MostrarEstat(3);

static void MostrarEstat(int unitats)
{
    if (unitats < 5)
    {
        Console.WriteLine("Cal revisar l'estoc");
    }
}

2. Què és una classe? I un objecte?

Una classe és una definició o plantilla: indica quines dades i comportaments tindran els seus objectes. Un objecte és un exemplar concret creat a partir d'aquesta classe. Un producte real té nom i unitats i pot rebre noves unitats.

C#Producte.cs
public class Producte
{
    public string Nom { get; }
    public int Unitats { get; private set; }

    public Producte(string nom, int unitats)
    {
        Nom = nom;
        Unitats = unitats;
    }

    public void Afegir(int novesUnitats)
    {
        if (novesUnitats > 0)
        {
            Unitats += novesUnitats;
        }
    }
}

En aquest exemple Producte és la classe; Nom i Unitats són propietats; Producte(...) és el constructor; Afegir és un mètode d'instància. private set impedeix que una altra part del programa canviï directament Unitats.

Ara creeu un fitxer Producte.cs al mateix projecte de consola i escriviu a Program.cs:

C#Program.cs
Producte teclat = new Producte("Teclat", 5);
Producte ratoli = new Producte("Ratolí", 12);

teclat.Afegir(3);
Console.WriteLine(teclat.Nom + ": " + teclat.Unitats);
Console.WriteLine(ratoli.Nom + ": " + ratoli.Unitats);

Les dues variables fan referència a objectes diferents. Afegir tres unitats a teclat no modifica ratoli. El punt (.) permet accedir a les propietats i als mètodes d'un objecte.

Per què ens interessa això en DAM_0488?

Quan treballeu amb Form1, Button o IndicadorEstoc, també estareu treballant amb classes i objectes. El formulari és un objecte; els botons que hi poseu són altres objectes amb propietats i esdeveniments.

3. Listes d'objectes

List<Producte> permet guardar diversos productes en una mateixa col·lecció. El tipus que apareix entre < > indica quin tipus d'elements accepta la llista.

C#Program.cs
List<Producte> productes = new();
productes.Add(new Producte("Teclat", 5));
productes.Add(new Producte("Ratolí", 12));

foreach (Producte producte in productes)
{
    Console.WriteLine(producte.Nom + ": " + producte.Unitats);
}

Console.WriteLine("Total: " + productes.Count);

Add afegeix elements; foreach els recorre; Count indica quants elements hi ha. Una List desa els objectes mentre l'aplicació s'està executant: no els guarda automàticament en disc. La persistència s'estudia a la unitat 1.

4. Visibilitat, encapsulació i responsabilitats

public vol dir que altres classes poden utilitzar el membre; private limita l'accés a la mateixa classe. Una classe hauria de protegir la coherència de les seves dades: per exemple, un producte no hauria d'acabar amb unitats negatives.

C#Mètode per a Producte.cs
public void Retirar(int unitats)
{
    if (unitats <= 0 || unitats > Unitats)
    {
        throw new ArgumentException("Quantitat no vàlida");
    }

    Unitats -= unitats;
}

Aquesta regla viu a la classe Producte, no repartida pels botons del formulari. És un primer exemple de separar la lògica de negoci de la interfície.

Practiqueu: Objectes reals

Afegiu a Producte el mètode Retirar(int unitats). Des de Program.cs, creeu dos productes, afegiu-los a una llista i mostreu-ne les unitats després d'una entrada i una sortida. Comproveu què passa si intenteu retirar més unitats de les disponibles.

Comprovació abans de continuar
  • Puc identificar classe, objecte, constructor i propietat.
  • Sé crear objectes amb new.
  • Sé cridar un mètode i explicar què és un paràmetre.
  • Sé guardar i recórrer objectes en una List<T>.
  • Entenc per què private set ajuda a protegir les dades.
