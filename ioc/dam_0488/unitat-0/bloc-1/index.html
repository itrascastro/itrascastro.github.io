1. Abans de programar: què construirem i què vol dir programar?

No cal haver programat mai. Aquesta unitat és un pont entre començar de zero i la Unitat 1. Els blocs s'han de seguir en ordre: primer llegir el concepte, després executar el codi, fer la petita modificació proposada i comprovar què ha passat. Llegir un programa no equival a saber-ne escriure un.

Un programa és una seqüència d'instruccions precises que transformen entrades (dades) en sortides (resultats). En una aplicació de finestres, moltes instruccions s'executen com a resposta a una acció: clicar un botó, escriure, seleccionar una fila o tancar el formulari.

2. Obre Visual Studio i crea un projecte que funcioni

  1. Obriu Visual Studio i premeu Create a new project.
  2. Busqueu Windows Forms App, llenguatge C#; no trieu Windows Forms App (.NET Framework).
  3. Poseu de nom ProvesCSharp i trieu una carpeta fàcil de localitzar.
  4. Seleccioneu .NET 10 si és el que heu instal·lat i confirmeu la creació.
  5. Obriu el dissenyador de Form1.cs, premeu F5 i comproveu que apareix una finestra buida. Tanqueu-la.

L'exemple final del bloc 4 és MiniInventari (un projecte diferent): ara només practiquem amb ProvesCSharp.

A l'Explorador de solucions: Program.cs arrenca l'aplicació; Form1.cs conté la nostra lògica; Form1.Designer.cs és la part generada pel dissenyador. No modifiqueu Form1.Designer.cs manualment. Per alternar disseny/codi, clic dret sobre el formulari → View Designer / View Code.

3. Variables: donar nom a una dada

Una variable és una dada que té tipus, nom i valor. El tipus determina quins valors i operacions hi caben; el nom permet referir-nos-hi; el valor és el que guarda en aquell moment. El signe = assigna un valor; == compara dos valors.

Figura
CSHARP
string nom = "Teclat";        // text
int estoc = 8;               // nombre enter
decimal preu = 25.50m;       // diners: el sufix m indica decimal
bool disponible = true;      // sí o no
estoc = estoc + 2;           // ara estoc val 10
decimal import = preu * estoc;

El punt i coma ; tanca una instrucció. Les claus { } agrupen instruccions, // introdueix un comentari, les cometes indiquen una cadena i m és necessària per a un literal decimal. En el codi, els decimals es representen amb punt; en formularis, TryParse llegeix el separador decimal segons la configuració regional.

Proveu-ho. Col·loqueu un Button al formulari, canvieu-li la propietat (Name) a btnProva, feu-hi doble clic i, dins de l'esdeveniment Click generat, escriviu:

CSHARP
string nom = "Teclat";
int unitats = 8;
unitats += 2;
MessageBox.Show($"{nom}: {unitats} unitats");

Premeu F5 i cliqueu el botó: ha de sortir Teclat: 10 unitats. El signe $ davant la cadena permet incrustar variables entre claus. Canvieu el nom i les unitats i torneu a executar. Si això funciona, ja heu escrit el primer comportament d'un formulari.

4. Decisions i repeticions: if, for i foreach

if executa codi només si una expressió és certa. else expressa el camí alternatiu. Amb && exigim que dues condicions siguin certes; amb || n'hi ha prou que ho sigui una.

CSHARP
int estoc = 3;
if (estoc == 0)
{
    MessageBox.Show("Esgotat");
}
else if (estoc < 5)
{
    MessageBox.Show("Queden poques unitats");
}
else
{
    MessageBox.Show("Disponible");
}

Els bucles permeten repetir sense copiar instruccions. for és útil quan necessitem un comptador; foreach, quan recorrem els elements d'una col·lecció.

CSHARP
for (int i = 0; i < 3; i++)
{
    // i pren els valors 0, 1 i 2
    System.Diagnostics.Debug.WriteLine(i);
}

string[] noms = { "Teclat", "Ratolí", "Pantalla" };
foreach (string nom in noms)
{
    System.Diagnostics.Debug.WriteLine(nom);
}
Figura

Obriu View → Output i seleccioneu Debug per veure aquestes sortides. foreach no modifica una llista directament mentre la recorre: si cal eliminar elements, estudiarem una operació específica al bloc 2.

Repte: mostreu "Cal reposar" quan estoc valgui 0, 1, 2, 3 o 4; en qualsevol altre cas, "Estoc suficient". Proveu 0, 4 i 5: aquests són els valors límit que detecten errors.

5. Mètodes: posar nom a una operació i reutilitzar-la

Un mètode agrupa passos amb un nom. Els paràmetres són les dades que rep; el retorn és el resultat. Si no retorna res, utilitzem void. És la base per escriure codi llegible i no duplicar validacions en cada botó.

CSHARP
private decimal CalcularImport(decimal preu, int unitats)
{
    return preu * unitats;
}

private bool TeEstocBaix(int unitats)
{
    return unitats < 5;
}

// Exemples dins del Click del botó:
decimal total = CalcularImport(12.50m, 3);
bool baix = TeEstocBaix(3);
MessageBox.Show($"Total: {total:C2}; baix: {baix}");

Els dos mètodes han d'estar dins de la classe Form1, però fora de btnProva_Click. Les tres últimes instruccions, en canvi, van dins del mètode Click. Aquesta diferència és un error habitual quan es comença.

Figura

Comprovació: CalcularImport(12.50m, 3) ha de retornar 37.50m. Canvieu el paràmetre d'unitats a 4, expliqueu el nou resultat i després creeu un mètode EsPreuValid(decimal preu) que retorni true si el preu és zero o superior.

  1. Distingeix entre =, == i != sense consultar la teoria.
  2. Explica per què decimal preu = 19.95; no és correcte i com arreglar-ho.
  3. Construeix un botó que mostri "Majors d'edat" només si edat >= 18.
  4. Escriu un foreach que mostri quatre noms a la finestra Output.
  5. Canvia el mètode CalcularImport perquè retorni també el descompte del 10 % si les unitats són cinc o més.
