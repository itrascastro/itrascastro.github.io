1. Repte final: crea una aplicació real des de zero

Construirem MiniInventari, una aplicació molt petita per controlar el material d'una botiga. És un exemple formatiu, diferent del projecte d'avaluació: s'ha pensat per practicar les tècniques que necessitareu als EAC, no per substituir les instruccions particulars de cap enunciat. Podeu trobar també el projecte de referència a GitHub, amb instruccions i tots els fitxers.

Figura

Les regles són fàcils de comprovar: el codi no pot ser buit ni repetit (ignorant majúscules); el nom és obligatori; preu i estoc no són negatius; el codi d'un producte existent no es modifica. El cercador filtra per nom o codi sense perdre dades. El CSV exporta la llista completa, no només la vista filtrada.

Com sabrem que funciona? Amb la taula de proves de la secció 7: no n'hi ha prou amb veure la finestra. Ha de mostrar missatges adequats davant d'entrades incorrectes, respectar duplicats i actualitzar les dades després de cada operació.

3. Implementa Producte.cs i GestorProductes.cs

Pas A: model. Substituïu el contingut de Producte.cs per aquest codi complet. Cada objecte tindrà quatre propietats i un mètode que calcula el valor de l'estoc.

CSHARP
namespace MiniInventari;

public class Producte
{
    public string Codi { get; set; } = "";
    public string Nom { get; set; } = "";
    public decimal Preu { get; set; }
    public int Estoc { get; set; }

    public decimal ValorEnEstoc() => Preu * Estoc;
}

Pas B: gestor. Substituïu el contingut de GestorProductes.cs. És l'únic propietari de la llista. Torna còpies de la llista per mostrar i filtrar, de manera que el cercador no destrueix les dades originals.

CSHARP
namespace MiniInventari;

public class GestorProductes
{
    private readonly List<Producte> productes = new();

    public int Comptador => productes.Count;
    public decimal ValorTotal => productes.Sum(p => p.ValorEnEstoc());

    public List<Producte> Llistar() => productes.ToList();

    public List<Producte> Cercar(string text)
    {
        if (string.IsNullOrWhiteSpace(text)) return Llistar();
        return productes
            .Where(p => p.Codi.Contains(text, StringComparison.OrdinalIgnoreCase)
                     || p.Nom.Contains(text, StringComparison.OrdinalIgnoreCase))
            .ToList();
    }

    public bool Afegir(Producte producte)
    {
        if (productes.Any(p => p.Codi.Equals(
                producte.Codi, StringComparison.OrdinalIgnoreCase)))
            return false;

        productes.Add(producte);
        return true;
    }

    public bool Modificar(string codi, string nom, decimal preu, int estoc)
    {
        Producte? producte = productes.Find(p => p.Codi.Equals(
            codi, StringComparison.OrdinalIgnoreCase));
        if (producte is null) return false;

        producte.Nom = nom;
        producte.Preu = preu;
        producte.Estoc = estoc;
        return true;
    }

    public bool Eliminar(string codi)
    {
        Producte? producte = productes.Find(p => p.Codi.Equals(
            codi, StringComparison.OrdinalIgnoreCase));
        return producte is not null && productes.Remove(producte);
    }
}

Llegiu-lo en lloc de memoritzar-lo: productes és un camp privat, Comptador és una propietat només de lectura, Any pregunta si existeix algun element amb el mateix codi, Find retorna el primer coincident o null, i Where(...).ToList() crea un nou llistat filtrat. bool indica si una operació ha tingut èxit. Aquí no hi ha ni finestres ni MessageBox.

Comprovació d'aquest pas: compileu amb Ctrl+Shift+B. Si apareixen errors, reviseu el nom del projecte i el namespace MiniInventari, les claus i els noms de fitxer. No continueu amb la interfície fins que el model i el gestor no compilin.

5. Escriu el comportament complet a Form1.cs

El fitxer següent és complet: conté configuració, validació, refresc de la taula, selecció, CRUD, cerca i CSV. Conserveu els controls creats al dissenyador, buideu el contingut del Form1.cs generat i enganxeu-hi aquesta classe (no el fitxer Form1.Designer.cs). Els noms dels controls i els set esdeveniments han de coincidir amb els de la secció anterior.

CSHARP
using System.Globalization;
using System.Text;

namespace MiniInventari;

public partial class Form1 : Form
{
    private readonly GestorProductes gestor = new();
    private string? codiSeleccionat;
    private bool actualitzantTaula;

    public Form1()
    {
        InitializeComponent();
        ConfigurarGraella();
        RefrescarGraella();
        NetejarCamps(false);
    }

    private void ConfigurarGraella()
    {
        dgvProductes.AutoGenerateColumns = true;
        dgvProductes.ReadOnly = true;
        dgvProductes.MultiSelect = false;
        dgvProductes.AllowUserToAddRows = false;
        dgvProductes.SelectionMode = DataGridViewSelectionMode.FullRowSelect;
        dgvProductes.AutoSizeColumnsMode =
            DataGridViewAutoSizeColumnsMode.Fill;
    }

    private bool ValidarFormulari(out Producte producte)
    {
        producte = new Producte();
        string codi = txtCodi.Text.Trim();
        string nom = txtNom.Text.Trim();

        if (string.IsNullOrWhiteSpace(codi))
        {
            MessageBox.Show("Introduïu un codi.");
            txtCodi.Focus();
            return false;
        }
        if (string.IsNullOrWhiteSpace(nom))
        {
            MessageBox.Show("Introduïu un nom.");
            txtNom.Focus();
            return false;
        }
        if (!decimal.TryParse(txtPreu.Text,
            NumberStyles.Number, CultureInfo.CurrentCulture,
            out decimal preu) || preu < 0m)
        {
            MessageBox.Show("El preu ha de ser un número no negatiu.");
            txtPreu.Focus();
            return false;
        }
        if (!int.TryParse(txtEstoc.Text, out int estoc) || estoc < 0)
        {
            MessageBox.Show("L'estoc ha de ser un enter no negatiu.");
            txtEstoc.Focus();
            return false;
        }

        producte = new Producte
        {
            Codi = codi, Nom = nom, Preu = preu, Estoc = estoc
        };
        return true;
    }

    private void RefrescarGraella()
    {
        actualitzantTaula = true;
        try
        {
            dgvProductes.DataSource = null;
            dgvProductes.DataSource = gestor.Cercar(txtCerca.Text.Trim());
            dgvProductes.ClearSelection();
            dgvProductes.CurrentCell = null;
            lblResum.Text = $"{gestor.Comptador} productes · {gestor.ValorTotal:C2}";
        }
        finally
        {
            actualitzantTaula = false;
        }
    }

    private void NetejarCamps(bool donarFocus = true)
    {
        codiSeleccionat = null;
        txtCodi.ReadOnly = false;
        txtCodi.Clear();
        txtNom.Clear();
        txtPreu.Clear();
        txtEstoc.Clear();
        btnModificar.Enabled = false;
        btnEliminar.Enabled = false;
        dgvProductes.ClearSelection();
        dgvProductes.CurrentCell = null;
        if (donarFocus) txtCodi.Focus();
    }

    private void btnAfegir_Click(object sender, EventArgs e)
    {
        if (!ValidarFormulari(out Producte nou)) return;

        if (!gestor.Afegir(nou))
        {
            MessageBox.Show("Aquest codi ja existeix.");
            return;
        }
        RefrescarGraella();
        NetejarCamps();
    }

    private void dgvProductes_SelectionChanged(object sender, EventArgs e)
    {
        if (actualitzantTaula) return;
        if (dgvProductes.CurrentRow?.DataBoundItem is not Producte p)
            return;

        codiSeleccionat = p.Codi;
        txtCodi.Text = p.Codi;
        txtCodi.ReadOnly = true; // la clau no es pot canviar
        txtNom.Text = p.Nom;
        txtPreu.Text = p.Preu.ToString(CultureInfo.CurrentCulture);
        txtEstoc.Text = p.Estoc.ToString();
        btnModificar.Enabled = true;
        btnEliminar.Enabled = true;
    }

    private void btnModificar_Click(object sender, EventArgs e)
    {
        if (codiSeleccionat is null) return;
        if (!ValidarFormulari(out Producte dades)) return;

        if (!gestor.Modificar(codiSeleccionat,
            dades.Nom, dades.Preu, dades.Estoc))
        {
            MessageBox.Show("El producte seleccionat ja no existeix.");
            return;
        }
        RefrescarGraella();
        NetejarCamps();
    }

    private void btnEliminar_Click(object sender, EventArgs e)
    {
        if (codiSeleccionat is null) return;
        DialogResult resposta = MessageBox.Show(
            $"Voleu eliminar {codiSeleccionat}?",
            "Confirma l'eliminació",
            MessageBoxButtons.YesNo, MessageBoxIcon.Question);

        if (resposta != DialogResult.Yes) return;

        gestor.Eliminar(codiSeleccionat);
        RefrescarGraella();
        NetejarCamps();
    }

    private void btnNetejar_Click(object sender, EventArgs e)
    {
        NetejarCamps();
    }

    private void txtCerca_TextChanged(object sender, EventArgs e)
    {
        RefrescarGraella();
        NetejarCamps(false); // no traiem el focus del cercador
    }

    private static string CampCsv(string valor)
    {
        return "\"" + valor.Replace("\"", "\"\"") + "\"";
    }

    private void btnExportar_Click(object sender, EventArgs e)
    {
        using SaveFileDialog dialeg = new SaveFileDialog
        {
            Filter = "Fitxers CSV (*.csv)|*.csv",
            FileName = "productes.csv"
        };
        if (dialeg.ShowDialog() != DialogResult.OK) return;

        List<string> linies = new() { "Codi;Nom;Preu;Estoc" };
        foreach (Producte p in gestor.Llistar())
        {
            linies.Add($"{CampCsv(p.Codi)};{CampCsv(p.Nom)};" +
                $"{p.Preu.ToString(CultureInfo.CurrentCulture)};{p.Estoc}");
        }

        try
        {
            File.WriteAllLines(dialeg.FileName, linies, new UTF8Encoding(true));
            MessageBox.Show("CSV exportat correctament.");
        }
        catch (IOException)
        {
            MessageBox.Show("No s'ha pogut escriure el fitxer.");
        }
        catch (UnauthorizedAccessException)
        {
            MessageBox.Show("No teniu permisos per desar en aquesta carpeta.");
        }
    }
}

Segueix el recorregut d'un clic a Afegir: btnAfegir_Click → ValidarFormulari → gestor.Afegir → RefrescarGraella → NetejarCamps. Si la validació falla, return impedeix continuar. Si el codi és duplicat, la capa de negoci rebutja l'alta, i el formulari informa.

Segueix el recorregut d'una edició: seleccionar una fila → SelectionChanged copia el producte als camps → el codi esdevé de només lectura → modificar el nom o l'estoc → clicar Modificar → gestor.Modificar. No es crea cap objecte duplicat.

Segueix el filtre: TextChanged consulta una còpia filtrada de la llista. actualitzantTaula evita que un esdeveniment intern de selecció ompli els camps durant el refresc. La cerca no elimina ni modifica productes.

El CSV: escriu a la ruta triada, amb capçalera, codificació UTF-8 i escapament de les cometes als camps de text. Exportar no és desar automàticament: l'exemple no torna a carregar fitxers en obrir-se.

6. Execució guiada: d'una taula buida a CRUD i cerca

  1. Ctrl+Shift+B. La solució ha de compilar sense errors. Si el compilador indica que un control no existeix, comproveu el seu (Name) al dissenyador. Si indica controlador duplicat, elimineu només el duplicat de Form1.cs, no el control.
  2. F5. La taula s'obre buida i lblResum mostra zero productes. Proveu Afegir sense escriure: ha d'aparèixer un missatge de validació.
  3. Producte 1. Codi P001, nom Teclat, preu 25,50 o 25.50 segons la regió, estoc 10. Premeu Afegir.
  4. Producte 2. Codi P002, nom Ratolí, preu 18, estoc 5. Premeu Afegir. El valor total ha de ser 345 (moneda segons configuració).
  5. Modificar. Seleccioneu P001, canvieu l'estoc a 2 i premeu Modificar. El total passa a 141 (51 + 90). El recompte continua sent dos.
  6. Cercar. Escriviu rat al cercador: només es mostra P002. Esborreu el filtre: tornen a aparèixer els dos productes.
  7. Eliminar. Seleccioneu P002, premeu Eliminar i cancel·leu (no canvia res). Repetiu i confirmeu: queda només P001.
  8. CSV. Premeu Exportar CSV, trieu una carpeta amb permisos i obriu el fitxer amb un editor de text. La capçalera és Codi;Nom;Preu;Estoc.

7. Bateria de proves: què significa que està ben fet?

Una aplicació aparentment correcta pot tenir errors als casos límit. Executeu i registreu els resultats, no marqueu «correcte» sense haver-ho provat.

CasAccióResultat esperat
01Afegir amb codi buit o només espaisMissatge; no s'afegeix res.
02Afegir sense nomMissatge; no s'afegeix res.
03Preu abcMissatge; cap excepció.
04Estoc -1 o 1,5Rebutjat: ha de ser enter i no negatiu.
05Preu i estoc zeroAdmesos: són valors vàlids.
06Afegir P001 i després p001Rebutjat el duplicat, també amb altres majúscules.
07Modificar un producte seleccionatCanvien nom/preu/estoc, no el codi ni el nombre de files.
08Prémer Eliminar i respondre «No»No s'elimina res.
09Cerca parcial per nom i codiNomés es filtra la vista; en buidar la cerca reapareix tot.
10Exportar després de cercarS'exporten tots els productes del gestor.
11Cancel·lar el diàleg de CSVNo s'escriu cap fitxer i no hi ha error.
12Redimensionar i navegar amb TabEls camps continuen accessibles i la graella és utilitzable.

Depuració guiada: poseu un punt d'interrupció a ValidarFormulari, un a GestorProductes.Afegir i un a RefrescarGraella. Afegiu un producte amb F5/F10 i observeu el recorregut. En un duplicat s'arriba a la validació i al gestor, però la nova alta no s'accepta.
