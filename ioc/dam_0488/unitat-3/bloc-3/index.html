1. Cicle de vida d'una aplicació i distribució

La distribució és la fase final del cicle de vida d'una aplicació: un cop desenvolupada i provada, cal preparar-la perquè arribi a l'usuari final en un format instal·lable i fàcil d'usar, sense necessitat que aquest tingui instal·lades les eines de desenvolupament.

2. Empaquetament d'una aplicació .NET

El SDK de .NET inclou l'ordre dotnet publish, que genera una versió de l'aplicació preparada per distribuir, amb diverses opcions:

OpcióEfecte
Framework-dependent (per defecte)L'ordinador de destí ha de tenir instal·lat el runtime de .NET corresponent.
--self-containedInclou el runtime de .NET dins del paquet: l'usuari final no necessita instal·lar res prèviament, a canvi d'una mida de paquet més gran.
-p:PublishSingleFile=trueCombina tots els fitxers necessaris en un únic executable.
-r <runtime identifier>Especifica la plataforma de destí (per exemple win-x64).
BASH 
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

Aplicat a TallerVeu, aquesta ordre genera un únic TallerVeu.exe autònom de 155 MB (inclou tot el runtime de .NET i les llibreries de Windows Forms), que s'ha comprovat que arrenca correctament sense cap instal·lació prèvia del SDK ni del runtime.

3. Crear un instal·lador

EinaCaracterístiques
Inno SetupEina gratuïta molt utilitzada per crear instal·ladors clàssics (.exe) personalitzables mitjançant un script de text.
WiX ToolsetEina de codi obert per generar paquets .msi, amb més control i complexitat que Inno Setup.
MSIXFormat modern d'empaquetat de Microsoft, amb instal·lació i desinstal·lació netes i suport per a actualitzacions automàtiques.

Amb independència de l'eina triada, un paquet d'instal·lació complet ha d'incloure totes les dependències necessàries perquè l'aplicació funcioni a l'ordinador de destí sense passos manuals addicionals.

3.1. Script d'Inno Setup per a TallerVeu

  1. Descarregar i instal·lar Inno Setup des del seu lloc oficial.
  2. Generar prèviament la versió distribuïble amb dotnet publish (apartat anterior).
  3. Obrir Inno Setup i triar Create a new script file using the Script Wizard, o escriure l'script directament.
  4. Compilar l'script (Build → Compile) per obtenir l'instal·lador final.
INI 
[Setup]
AppName=TallerVeu
AppVersion=1.0
DefaultDirName={autopf}\TallerVeu
DefaultGroupName=TallerVeu
OutputBaseFilename=Instal·lador_TallerVeu
Compression=lzma2
SolidCompression=yes

[Files]
Source: "..\TallerVeu\bin\Release\net8.0-windows\win-x64\publish\*"; DestDir: "{app}"; Flags: recursesubdirs

[Icons]
Name: "{group}\TallerVeu"; Filename: "{app}\TallerVeu.exe"
Name: "{group}\Desinstal·la TallerVeu"; Filename: "{uninstallexe}"
Name: "{autodesktop}\TallerVeu"; Filename: "{app}\TallerVeu.exe"; Tasks: icona_escriptori

[Tasks]
Name: "icona_escriptori"; Description: "Crea una icona a l'escriptori"; GroupDescription: "Icones addicionals:"
Important

Verifiqueu sempre l'script abans de donar-lo per bo

Un script .iss sintàcticament correcte no garanteix un instal·lador funcional: cal compilar-lo (ISCC.exe, o el botó Build → Compile dins d'Inno Setup) i comprovar realment que l'instal·lador resultant instal·la i desinstal·la l'aplicació sense errors, abans de donar-lo per bo en un projecte real.

La secció [Icons] amb {uninstallexe} és el que garanteix que es crea una entrada de desinstal·lació neta, accessible tant des del menú d'inici com des de Configuració. La secció [Tasks] amb icona_escriptori deixa l'accés directe a l'escriptori com a opcional, no obligatori.

3.2. WiX Toolset i MSIX: quan es fan servir

WiX genera paquets .msi a partir d'un fitxer XML que descriu components, carpetes i registre; té una corba d'aprenentatge més pronunciada que Inno Setup però és l'estàndard de facto en molts entorns empresarials .NET. MSIX és el format més modern de Microsoft, pensat per a instal·lació i actualització a través de la Microsoft Store o de sistemes de gestió d'aplicacions corporatius. Per a un primer instal·lador funcional i senzill de mantenir, Inno Setup sol ser suficient.

4. Personalització i desinstal·lació

Un instal·lador ben preparat permet personalitzar aspectes com el logotip, els diàlegs de benvinguda, l'idioma o la carpeta de destí, i ha de deixar sempre una via clara per desinstal·lar l'aplicació de manera neta (retirant fitxers, dreceres i entrades de registre creades durant la instal·lació).

El paquet de distribució de TallerVeu inclou també un README_instal·lacio.txt, amb els requisits (Windows 64 bits, micròfon i altaveus, cap dependència addicional gràcies al --self-contained), els passos d'instal·lació i desinstal·lació, i les dependències i permisos necessaris (accés al micròfon).
