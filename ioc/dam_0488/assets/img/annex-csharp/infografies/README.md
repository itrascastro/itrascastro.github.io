## Criteris didàctics

- Les imatges es presenten al costat de l'explicació que il·lustren, no com un àlbum separat.
- Els fragments de codi **copiables de les pàgines HTML** són la referència tècnica; els petits fragments dibuixats a les infografies són recursos gràfics orientatius.
- Les representacions d'interfície de Visual Studio que apareixen dins de les infografies són recreacions didàctiques. Les captures reals del mòdul estan disponibles a la Unitat 1 i també són referenciades a l'annex.
- Els camps i classes de les imatges més avançades no coincideixen necessàriament amb el petit projecte `MiniCataleg`: les diferències es descriuen als peus de figura.
- Aquestes infografies no canvien les unitats oficials ni afegeixen resultats d'aprenentatge.

Els fitxers SVG de la carpeta superior són esquemes vectorials complementaris i editables.
