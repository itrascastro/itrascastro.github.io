Introducció

En aquest cas d'ús pràctic, integrareu tots els conceptes treballats a la Unitat 2 per construir una aplicació completa de catàleg d'elements amb Angular. Desenvolupareu una interfície interactiva que inclou components personalitzats, gestió d'esdeveniments, formularis amb FormsModule i funcionalitats d'accessibilitat.

Aquest cas d'ús representa un projecte realista que us permetrà aplicar els coneixements adquirits sobre components, comunicació entre components, directives, pipes, formularis i accessibilitat en un context integrat.

Objectius

En finalitzar aquest cas d'ús, hauríeu de ser capaços de:

  • Crear components Angular reutilitzables amb responsabilitats clares
  • Implementar la comunicació entre components pare-fill utilitzant @Input i @Output
  • Construir un formulari de filtres amb FormsModule, validacions i missatges d'ajuda
  • Aplicar el control de flux (@for, @if, @empty) i pipes per controlar la renderització
  • Gestionar diferents estats de la interfície (càrrega, sense resultats, contingut, detall)
  • Implementar característiques d'accessibilitat (labels, ARIA, focus visible, teclat)

Criteris d'avaluació (RA2)

Aquest cas d'ús cobreix els criteris del Resultat d'Aprenentatge 2:

  • RA2.1: Divideix la interfície en peces senzilles i reutilitzables amb responsabilitats clares
  • RA2.2: Mostra informació dinàmica utilitzant tècniques de vinculació de dades i plantilles
  • RA2.3: Construeix formularis amb camps, validacions i missatges d'ajuda
  • RA2.4: Gestiona esdeveniments habituals i la comunicació entre parts de la interfície
  • RA2.5: Comprova el funcionament general i ajusta la presentació i el comportament quan cal

2. Visió general de l'aplicació

2.1. Què construireu

Construireu una aplicació de catàleg amb 4 parts principals:

  1. Component de targeta — Mostra un element (etiqueta de categoria, data, títol, descripció, valoració) i permet seleccionar-lo
  2. Llistat d'elements — Itera l'array amb @for (...; track ...) i mostra múltiples targetes
  3. Barra de filtres — Formulari amb text i categoria, validacions i botó de restabliment, que filtra el llistat
  4. Panell de detall — Mostra l'element seleccionat
  5. Estats visuals — Missatges de "carregant", "sense resultats", "X resultats trobats"

2.2. Flux d'usuari

  1. Aplicació carrega amb llistat complet visible
  2. Usuari escriu text (opcional, mínim 3 caràcters), tria una categoria i aplica els filtres
  3. Llistat es filtra segons els dos criteris; "Restablir" torna a mostrar-ho tot
  4. Usuari selecciona una targeta i el panell de detall mostra les seves dades
  5. Estats visuals actualitzen segons context

3. Component de targeta reutilitzable

Objectiu: Crear el model de dades, un subcomponent d'etiqueta i la targeta que mostra un element individual, rep dades amb @Input i avisa amb @Output quan l'usuari la selecciona.

Integra conceptes de: Lectura 2.1.1 (components), 2.1.2 (vinculació de propietats), 2.1.3 (@Input, @Output) i 2.2.3 (pipes).

Sobre els fitxers: el projecte està configurat amb --file-name-style-guide=2016, de manera que cada ng generate component crea nom.component.ts, nom.component.html i nom.component.scss. En aquest cas d'ús escriurem la plantilla i els estils als fitxers generats, que és la convenció del mòdul. Recordeu també que la CLI genera la classe sense sufix (TargetaElement): reanomeneu-la amb F2 a TargetaElementComponent tal com vau fer a la Lectura 2.1.1, o afegiu --add-type-to-class-name a la comanda.

3.1. Crear model de dades

Primer, definiu la interfície Element que representa les dades d'un element del catàleg. L'opció --type=model fa que el fitxer es digui element.model.ts:

BASH 
ng generate interface models/element --type=model

Fitxer src/app/models/element.model.ts:

TYPESCRIPT 
export type CategoriaElement = 'Electrònica' | 'Àudio' | 'Accessoris' | 'Pantalles' | 'Energia';

export interface Element {
  id: number;
  titol: string;
  descripcio: string;
  categoria: CategoriaElement;
  dataActualitzacio: string;   // ISO 8601, per exemple '2026-09-10'
  valoracio: number;           // de 0 a 5
  destacat?: boolean;
}

El tipus CategoriaElement limita les categories a una llista tancada: TypeScript avisarà si algú escriu una categoria que no existeix, i més endavant el reutilitzarem per omplir el selector de filtres.

3.3. Generar i implementar la targeta

BASH 
ng generate component components/targeta-element

La targeta rep l'element del pare (@Input), sap si està seleccionada (@Input opcional) i avisa el pare quan l'usuari prem el botó de detall (@Output). Com que la plantilla fa servir el pipe date, cal importar DatePipe:

Fitxer src/app/components/targeta-element/targeta-element.component.ts:

TYPESCRIPT 
import { Component, EventEmitter, Input, Output } from '@angular/core';
import { DatePipe } from '@angular/common';
import { Element } from '../../models/element.model';
import { EtiquetaElementComponent } from '../etiqueta-element/etiqueta-element.component';

@Component({
  imports: [DatePipe, EtiquetaElementComponent],
  selector: 'app-targeta-element',
  styleUrl: './targeta-element.component.scss',
  templateUrl: './targeta-element.component.html',
})
export class TargetaElementComponent {
  @Input({ required: true }) element!: Element;
  @Input() seleccionada = false;
  @Output() selecciona = new EventEmitter<Element>();

  avisaSeleccio(): void {
    this.selecciona.emit(this.element);
  }
}

Aspectes clau del codi:

  • @Input({ required: true }) element — Angular no compila si algú usa la targeta sense passar-li un element
  • @Output() selecciona + emit(this.element) — La targeta no decideix què passa en seleccionar-la: només avisa
  • element.dataActualitzacio | date:'dd/MM/yyyy' — Format de data amb pipe; DatePipe importat al component
  • [destacat]="element.destacat ?? false" — L'operador ?? converteix un camp opcional en un booleà segur
  • [class.seleccionada]="seleccionada" — Classe condicional per ressaltar la targeta activa
  • <time [attr.datetime]> i el text ocult de l'etiqueta — Semàntica i accessibilitat sense cost visual

4.3. Implementar llistat amb iteració

El llistat és un intermediari: rep els elements i l'identificador del seleccionat, i torna a emetre cap amunt la selecció que li arriba de cada targeta.

Fitxer src/app/components/llista-elements/llista-elements.component.ts:

TYPESCRIPT 
import { Component, EventEmitter, Input, Output } from '@angular/core';
import { Element } from '../../models/element.model';
import { TargetaElementComponent } from '../targeta-element/targeta-element.component';

@Component({
  imports: [TargetaElementComponent],
  selector: 'app-llista-elements',
  styleUrl: './llista-elements.component.scss',
  templateUrl: './llista-elements.component.html',
})
export class LlistaElementsComponent {
  @Input({ required: true }) elements: Element[] = [];
  @Input() elementSeleccionatId?: number;
  @Output() selecciona = new EventEmitter<Element>();

  propagaSeleccio(element: Element): void {
    this.selecciona.emit(element);
  }
}

Fitxer llista-elements.component.html:

HTML 
<section class="graella" aria-label="Llistat d'elements">
  @for (element of elements; track element.id) {
    <app-targeta-element
      [element]="element"
      [seleccionada]="element.id === elementSeleccionatId"
      (selecciona)="propagaSeleccio($event)" />
  } @empty {
    <p class="missatge-buit" role="status">No hi ha elements per mostrar.</p>
  }
</section>

Aspectes clau del codi:

  • @for (element of elements; track element.id) — Iteració amb seguiment per identificador
  • @empty — Missatge de llista buida sense cap @if addicional
  • [seleccionada]="element.id === elementSeleccionatId" — Només la targeta activa rep la classe de ressaltat
  • (selecciona)="propagaSeleccio($event)" — El llistat reemet l'esdeveniment de la targeta cap al component arrel
  • grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)) — Graella responsive automàtica

4.4. Component arrel amb panell de detall

El component arrel és qui guarda l'estat: la llista completa, l'element seleccionat i, més endavant, els filtres. Substituïu el codi de prova de la secció 3.4.

Fitxer src/app/app.component.ts:

TYPESCRIPT 
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';
import { LlistaElementsComponent } from './components/llista-elements/llista-elements.component';
import { ELEMENTS_MOCK } from './mocks/dades-mock';
import { Element } from './models/element.model';

@Component({
  imports: [RouterOutlet, LlistaElementsComponent],
  selector: 'app-root',
  styleUrl: './app.component.scss',
  templateUrl: './app.component.html',
})
export class App {
  elements: Element[] = ELEMENTS_MOCK;
  elementSeleccionat: Element | undefined = undefined;

  seleccionaElement(element: Element): void {
    this.elementSeleccionat = element;
  }

  tancaDetall(): void {
    this.elementSeleccionat = undefined;
  }
}

TYPESCRIPT 
import { Component, EventEmitter, Output } from '@angular/core';
import { FormsModule } from '@angular/forms';
import { CategoriaElement } from '../../models/element.model';

export interface FiltresElement {
  text: string;
  categoria: CategoriaElement | 'Totes';
}

@Component({
  imports: [FormsModule],
  selector: 'app-barra-filtres',
  styleUrl: './barra-filtres.component.scss',
  templateUrl: './barra-filtres.component.html',
})
export class BarraFiltresComponent {
  @Output() filtresCanviats = new EventEmitter<FiltresElement>();

  categories: Array<CategoriaElement | 'Totes'> = ['Totes', 'Electrònica', 'Àudio', 'Accessoris', 'Pantalles', 'Energia'];

    text: '',
    categoria: 'Totes',

  aplicaFiltres(): void {
    this.filtresCanviats.emit({ ...this.filtres });
  }

  restableixFiltres(): void {
    this.filtres = { text: '', categoria: 'Totes' };
    this.aplicaFiltres();
  }
}

Aspectes clau del codi:

  • [(ngModel)]="filtres.text" i [(ngModel)]="filtres.categoria" — Vinculació bidireccional dels dos criteris en un sol objecte
  • minlength="3" sense required — El text és opcional (buit = vàlid, per filtrar només per categoria), però si s'escriu ha de tenir tres caràcters; Angular converteix l'atribut en estat del control (campText.errors)

  • [disabled]="formulariFiltres.invalid" — El botó d'aplicar es desactiva mentre el formulari no és vàlid

  • Botó "Restablir" de tipus button — No envia el formulari; neteja els criteris i emet els filtres buits
  • role="alert", aria-describedby i focus-visible — Accessibilitat del formulari

5.3. Integrar filtres amb llistat i detall

El component arrel guarda la llista completa i una llista filtrada. En aplicar filtres, recalcula la llista filtrada combinant text i categoria; en restablir, torna a mostrar-ho tot.

Actualitzeu src/app/app.component.ts:

TYPESCRIPT 
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';
import { BarraFiltresComponent, FiltresElement } from './components/barra-filtres/barra-filtres.component';
import { LlistaElementsComponent } from './components/llista-elements/llista-elements.component';
import { ELEMENTS_MOCK } from './mocks/dades-mock';
import { Element } from './models/element.model';

@Component({
  imports: [RouterOutlet, BarraFiltresComponent, LlistaElementsComponent],
  selector: 'app-root',
  styleUrl: './app.component.scss',
  templateUrl: './app.component.html',
})
export class App {
  elements: Element[] = ELEMENTS_MOCK;
  elementsFiltrats: Element[] = ELEMENTS_MOCK;
  elementSeleccionat: Element | undefined = undefined;
  filtresActuals: FiltresElement = { text: '', categoria: 'Totes' };

  actualitzaFiltres(filtres: FiltresElement): void {
    this.filtresActuals = filtres;
    const text = filtres.text.trim().toLocaleLowerCase('ca');

    this.elementsFiltrats = this.elements.filter((element) => {
      const categoriaCoincideix = filtres.categoria === 'Totes' || element.categoria === filtres.categoria;
      const textCoincideix = text === '' || this.conteText(element, text);
      return categoriaCoincideix && textCoincideix;
    });

    // Si l'element seleccionat ha quedat fora del filtre, tanquem el detall
    if (this.elementSeleccionat && !this.elementsFiltrats.includes(this.elementSeleccionat)) {
      this.elementSeleccionat = undefined;
    }
  }

  seleccionaElement(element: Element): void {
    this.elementSeleccionat = element;
  }

  tancaDetall(): void {
    this.elementSeleccionat = undefined;
  }

  private conteText(element: Element, text: string): boolean {
    const contingut = `${element.titol} ${element.descripcio}`.toLocaleLowerCase('ca');
    return contingut.includes(text);
  }
}

6.2. Estat de càrrega inicial

Les dades ara són locals, però a la Unitat 3 arribaran d'una API i trigaran. Preparem l'estructura simulant la càrrega amb un temporitzador.

Un detall important d'Angular 22: els projectes nous funcionen sense zone.js. Això vol dir que Angular refresca la vista quan s'executa un gestor d'esdeveniments de la plantilla (com (click) o (ngSubmit)) o quan canvia un signal que la plantilla llegeix; però no vigila una propietat normal que canvieu dins d'un setTimeout, d'una promesa o d'una resposta HTTP. Per a aquests casos, l'estat es guarda en un signal: signal(valorInicial) el crea, nom() el llegeix i nom.set(nouValor) el canvia. Ja el vau veure a la propietat title que genera la CLI, i el treballareu a fons a la Unitat 3.

Afegiu a app.component.ts:

TYPESCRIPT 
import { Component, signal } from '@angular/core';
// ... la resta d'importacions com abans

export class App {
  elements: Element[] = [];
  elementsFiltrats: Element[] = [];
  elementSeleccionat: Element | undefined = undefined;
  filtresActuals: FiltresElement = { text: '', categoria: 'Totes' };
  carregant = signal(true);

  constructor() {
    // Simulació de càrrega: a la Unitat 3 aquí hi haurà una petició HTTP
    setTimeout(() => {
      this.elements = ELEMENTS_MOCK;
      this.elementsFiltrats = ELEMENTS_MOCK;
      this.carregant.set(false);   // el canvi del signal fa que Angular refresqui la vista
    }, 800);
  }

  // ... actualitzaFiltres, seleccionaElement, tancaDetall i conteText com abans
}

9. Resolució de problemes i Autoavaluació

Problemes de components

Símptoma Causa Solució
Error NG8002: Can't bind to 'element' since it isn't a known property El component fill no és a l'array imports del pare Afegir TargetaElementComponent (o el component que toqui) a imports del component pare
Error NG8004: No pipe found with name 'date' Pipe no importat Afegir DatePipe a imports del component que l'usa
Targeta no es mostra Propietat @Input no rebuda Verificar sintaxi [element]="dada" al template pare
El pare no rep la selecció Nom de l'esdeveniment diferent de l'@Output o falta emit() Comprovar (selecciona)="..." al pare i this.selecciona.emit(this.element) al fill
Error NG5002: @for loop must have a "track" expression Falta l'expressió track Escriure @for (element of elements; track element.id)
La vista no canvia després d'un setTimeout o d'una resposta asíncrona Projecte sense zone.js: les propietats normals no disparen el refresc Guardar l'estat en un signal i canviar-lo amb set() (secció 6.2)

Problemes de formularis

Error Causa Solució Windows Solució Linux/macOS
FormsModule no reconegut Mòdul no importat Verificar imports del component Idem
Validació no funciona Atributs HTML incorrectes Revisar minlength, required, etc. Idem
[(ngModel)] error name attribute missing Afegir name="nomCamp" a input Idem

Problemes d'estils i responsive

Problema Causa Solució
Graella no responsive CSS Grid mal configurat Usar grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))
Focus no visible Estils globals sobrescrits Afegir :focus-visible { outline: 2px solid #1976d2; }
Spinner no gira Animació CSS falta Afegir @keyframes spin amb transform: rotate(360deg)

Problemes de TypeScript

Error Causa Solució
Property 'xxx' does not exist Tipus incorrecte Verificar interfície Element amb propietat xxx? opcional
Required input is not provided @Input obligatori sense valor Afegir [element]="dada" allà on s'usa el component; l'entrada ha de continuar sent obligatòria
Cannot find name 'ELEMENTS_MOCK' Import falta Afegir import { ELEMENTS_MOCK } from './mocks/dades-mock'
