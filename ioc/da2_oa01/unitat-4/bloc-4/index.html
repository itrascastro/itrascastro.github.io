Introducció

En aquest cas d'ús pràctic, integrareu tots els conceptes treballats al llarg del mòdul per convertir el catàleg d'elements de la Unitat 3 en una aplicació completa amb navegació real: diverses rutes amb URL pròpia, una vista de detall parametritzada amb pestanyes controlades per queryParams, una zona protegida amb autenticació simulada i returnUrl, una secció carregada de manera diferida amb preloading, i optimitzacions de rendiment (OnPush, virtualització amb Angular CDK i @defer) verificables al build de producció.

Aquest cas d'ús representa el projecte final integrador del mòdul. Parteix del codi que ja teniu (serveis HTTP, adaptadors, formulari reactiu, historial) i hi afegeix la capa de navegació i optimització sense reescriure el que funciona.

Objectius

En finalitzar aquest cas d'ús, hauríeu de ser capaços de:

  • Configurar un mapa de rutes standalone amb provideRouter, loadComponent, loadChildren i ruta comodí
  • Construir una navegació principal amb RouterLink, RouterLinkActive i un fil d'Ariadna
  • Llegir paràmetres de ruta i queryParams amb ActivatedRoute, i conservar l'estat de cerca a la URL
  • Navegar de manera programàtica amb Router
  • Implementar autenticació simulada amb estat reactiu (signals) i un guard funcional CanActivateFn amb returnUrl
  • Separar una secció amb lazy loading i activar el preloading
  • Escriure components compatibles amb OnPush (l'estratègia per defecte a Angular 22), virtualitzar una llista amb Angular CDK i diferir una secció amb @defer
  • Generar el build de producció i documentar-ne la mida inicial i els chunks lazy

3.3. El shell: capçalera, navegació i fil d'Ariadna

El component arrel deixa de mostrar contingut propi: només la capçalera amb la navegació, el fil d'Ariadna i el <router-outlet />. El fil d'Ariadna es construeix a partir de la ruta activa cada cop que acaba una navegació (NavigationEnd), llegint el data.breadcrumb de cada tram.

Fitxer src/app/app.component.ts:

TYPESCRIPT 
import { Component, inject, signal } from '@angular/core';
import { ActivatedRoute, NavigationEnd, Router, RouterLink, RouterLinkActive, RouterOutlet } from '@angular/router';
import { filter } from 'rxjs';

import { AuthService } from './services/auth.service';

interface Molla {
  etiqueta: string;
  url: string;
}

@Component({
  imports: [RouterOutlet, RouterLink, RouterLinkActive],
  selector: 'app-root',
  styleUrl: './app.component.scss',
  templateUrl: './app.component.html',
})
export class App {
  private readonly router = inject(Router);
  private readonly route = inject(ActivatedRoute);
  readonly auth = inject(AuthService);   // secció 5; fins llavors, comenteu aquesta línia i el seu ús a la plantilla

  readonly molles = signal<Molla[]>([]);

  constructor() {
    this.router.events.pipe(
      filter((event) => event instanceof NavigationEnd)
    ).subscribe(() => this.molles.set(this.construeixMolles()));
  }

  /** Recorre la ruta activa i recull els breadcrumb de cada nivell */
  private construeixMolles(): Molla[] {
    const molles: Molla[] = [{ etiqueta: 'Inici', url: '/' }];
    let url = '';
    let actual = this.route.root;

    while (actual.firstChild) {
      actual = actual.firstChild;
      const segments = actual.snapshot.url.map((s) => s.path).join('/');
      if (segments) {
        url += `/${segments}`;
      }
      const etiqueta = actual.snapshot.data['breadcrumb'];
      if (etiqueta && molles[molles.length - 1].etiqueta !== etiqueta) {
        molles.push({ etiqueta, url });
      }
    }
    return molles;
  }
}

4.2. Implementar la pàgina de detall

La pàgina combina dos fluxos d'ActivatedRoute: paramMap (l':id) i queryParamMap (la pestanya). Tots dos es converteixen en signals amb toSignal, de manera que si l'usuari passa d'un element a un altre sense sortir de la pàgina, la vista es refresca sola.

Fitxer src/app/pages/detall-page/detall-page.component.ts:

TYPESCRIPT 
import { Component, inject } from '@angular/core';
import { DecimalPipe } from '@angular/common';
import { toSignal } from '@angular/core/rxjs-interop';
import { ActivatedRoute, Router, RouterLink } from '@angular/router';
import { catchError, map, of, startWith, switchMap } from 'rxjs';

import { ElementCataleg } from '../../models/element.model';
import { ElementService } from '../../services/element.service';

type Pestanya = 'descripcio' | 'estoc';

interface EstatDetall {
  carregant: boolean;
  element?: ElementCataleg;
  error?: string;
}

@Component({
  imports: [RouterLink, DecimalPipe],
  selector: 'app-detall-page',
  styleUrl: './detall-page.component.scss',
  templateUrl: './detall-page.component.html',
})
export class DetallPageComponent {
  private readonly route = inject(ActivatedRoute);
  private readonly router = inject(Router);
  private readonly elementService = inject(ElementService);

  /** Pestanya activa, llegida de ?tab= (per defecte, descripció) */
  readonly pestanya = toSignal(
    this.route.queryParamMap.pipe(map((params): Pestanya => (params.get('tab') === 'estoc' ? 'estoc' : 'descripcio'))),
    { initialValue: 'descripcio' as Pestanya }
  );

  /** Element carregat a partir de :id; cada canvi de paràmetre torna a consultar l'API */
  readonly estat = toSignal(
    this.route.paramMap.pipe(
      map((params) => params.get('id') ?? ''),
      switchMap((id) => this.elementService.obtenirPerId(id).pipe(
        map((element): EstatDetall => ({ carregant: false, element })),
        catchError(() => of<EstatDetall>({ carregant: false, error: 'No s\'ha trobat cap element amb aquest identificador.' })),
        startWith<EstatDetall>({ carregant: true })
      ))
    ),
    { initialValue: { carregant: true } as EstatDetall }
  );

  /** Navegació programàtica: canvia la pestanya sense perdre l'id */
  canviaPestanya(tab: Pestanya): void {
    this.router.navigate([], {
      relativeTo: this.route,
      queryParams: { tab },
      queryParamsHandling: 'merge',
    });
  }

  tornaAlCataleg(): void {
    this.router.navigate(['/cataleg']);
  }
}

5.1. Servei d'autenticació

BASH

Fitxer src/app/services/auth.service.ts. L'estat viu en un signal privat exposat com a només lectura; computed deriva si hi ha sessió. Les credencials són simulades i fixes (documenteu-les al README):

TYPESCRIPT 
import { Service, computed, signal } from '@angular/core';

export interface Usuari {
  nom: string;
  rol: 'admin';
}

const CLAU_STORAGE = 'cataleg-usuari';
const CONTRASENYA_SIMULADA = 'ioc2026';

@Service()
export class AuthService {
  private readonly usuariSignal = signal<Usuari | null>(this.llegirSessio());

  /** Usuari actual (null si no hi ha sessió) */
  readonly usuari = this.usuariSignal.asReadonly();
  /** Cert si hi ha sessió iniciada */
  readonly autenticat = computed(() => this.usuariSignal() !== null);

  /** Autenticació simulada: qualsevol nom de 3+ caràcters amb la contrasenya fixa */
  inicia(nom: string, contrasenya: string): boolean {
    const nomNet = nom.trim();
    if (nomNet.length < 3 || contrasenya !== CONTRASENYA_SIMULADA) {
      return false;
    }
    const usuari: Usuari = { nom: nomNet, rol: 'admin' };
    this.usuariSignal.set(usuari);
    this.desarSessio(usuari);
    return true;
  }

  tanca(): void {
    this.usuariSignal.set(null);
    this.desarSessio(null);
  }

  private llegirSessio(): Usuari | null {
    try {
      const desat = localStorage.getItem(CLAU_STORAGE);
      return desat ? (JSON.parse(desat) as Usuari) : null;
    } catch {
      return null;
    }
  }

  private desarSessio(usuari: Usuari | null): void {
    try {
      if (usuari) {
        localStorage.setItem(CLAU_STORAGE, JSON.stringify(usuari));
      } else {
        localStorage.removeItem(CLAU_STORAGE);
      }
    } catch {
      // Sense persistència, la sessió dura fins que es tanca la pestanya
    }
  }
}

5.2. Guard funcional amb returnUrl

BASH 
ng generate guard guards/auth --implements=CanActivate

Fitxer src/app/guards/auth.guard.ts. Un guard funcional és una funció: injecta el que necessita amb inject() i retorna true per deixar passar o un UrlTree per redirigir. La URL sol·licitada (state.url) viatja com a returnUrl:

TYPESCRIPT 
import { inject } from '@angular/core';
import { CanActivateFn, Router } from '@angular/router';

import { AuthService } from '../services/auth.service';

export const authGuard: CanActivateFn = (_route, state) => {
  const auth = inject(AuthService);
  const router = inject(Router);

  if (auth.autenticat()) {
    return true;
  }

  // Redirecció amb la ruta original conservada
  return router.createUrlTree(['/login'], {
    queryParams: { returnUrl: state.url },
  });
};

Retornar un UrlTree (en lloc de cridar router.navigate i retornar false) és la forma recomanada: el Router cancel·la la navegació i en fa una de nova de manera atòmica, i el guard és fàcil de provar.

Important
Aquest mecanisme és exclusivament didàctic. Un guard del client no substitueix l'autenticació i l'autorització al servidor: tot el codi Angular s'executa al navegador de l'usuari i es pot modificar. El guard evita mostrar pantalles que no toquen; qui protegeix les dades és l'API, validant cada petició.

  private readonly router = inject(Router);

  readonly error = signal('');

    nom: new FormControl('', { nonNullable: true, validators: [Validators.required, Validators.minLength(3)] }),

Fitxer src/app/components/estadistiques-cataleg/estadistiques-cataleg.component.ts:

TYPESCRIPT 
import { ChangeDetectionStrategy, Component, Input } from '@angular/core';
import { DecimalPipe } from '@angular/common';

import { ElementCataleg } from '../../models/element.model';

@Component({
  imports: [DecimalPipe],
  selector: 'app-estadistiques-cataleg',
  styleUrl: './estadistiques-cataleg.component.scss',
  templateUrl: './estadistiques-cataleg.component.html',
  changeDetection: ChangeDetectionStrategy.OnPush,   // redundant a Angular 22: ja és el valor per defecte
})
export class EstadistiquesCatalegComponent {
  @Input({ required: true }) elements: ElementCataleg[] = [];

  get preuMitja(): number {
    if (this.elements.length === 0) return 0;
    return this.elements.reduce((suma, e) => suma + e.preu, 0) / this.elements.length;
  }

  get perCategoria(): { categoria: string; total: number }[] {
    const recompte = new Map<string, number>();
    for (const element of this.elements) {
      recompte.set(element.categoria, (recompte.get(element.categoria) ?? 0) + 1);
    }
    return [...recompte].map(([categoria, total]) => ({ categoria, total }));
  }
}
HTML 
<section class="estadistiques">
  <h2>Resum del catàleg</h2>
  <p>Elements: <strong>{{ elements.length }}</strong> · Preu mitjà: <strong>{{ preuMitja | number:'1.2-2' }} €</strong></p>
  <ul>
    @for (fila of perCategoria; track fila.categoria) {
      <li>{{ fila.categoria }}: {{ fila.total }}</li>
    }
  </ul>
</section>

7.5. Comprovar les optimitzacions

  1. OnPush: afegiu temporalment console.log('render llista') al getter d'un component de la llista i comproveu que no es repinta en escriure al camp de cerca fins que arriba una llista nova
